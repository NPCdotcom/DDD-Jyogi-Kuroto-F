# tasks/ai_log/

リーダー (＝AI 支援) の作業ログ置き場。**チーム共有資産ではない** 。

ここに置くもの:

- AI に作らせた成果物のレビュー記録 (サブエージェントの評価 + 反映内容)
- AI が起こした判断ミスと「次回どう動くか」の自己ルール (lessons)
- 試行錯誤の経緯メモ

チーム全員が読む必要は無いが、後で「あの設計判断ってどういう経緯だっけ？」を辿るために残す。

| **[handoff.md](./handoff.md)** | **現在の作業状態スナップショット**。ブランチ・直近の Issue/PR・次の作業・据置き判断のサマリ | ✅ **最優先** |
| [decisions.md](./decisions.md) | ADR (Architecture Decision Record) 風の不可逆判断ログ (ADR-01〜) | ✅ 判断経緯が必要な時 |
