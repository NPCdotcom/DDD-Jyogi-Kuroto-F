# 機能カテゴリと優先度

> 機能カテゴリ別の Issue 一覧。**担当は固定せず、各自が興味・スキルに応じて Issue を取る** 方式で運用する。
> 仕様の詳細は [GAME_DESIGN.md](./GAME_DESIGN.md) を参照。

---

## カテゴリA: コアゲームプレイ

| # | 機能 | 概要 | 優先度 |
|---|---|---|---|
| A-1 | AP制戦闘エンジン | 各エンティティのAP管理、ターン制御、行動コスト ([GAME_DESIGN.md §5-2](./GAME_DESIGN.md)) | P0 |
| A-2 | ダンジョン探索 | プレイヤー移動、宝箱、敵接触判定 | P0 |
| A-3 | スキル枠システム | 装着スキルの管理と発動 (MVP: 4枠) | P0 |
| A-4 | 死亡判定 | HP 0 で死亡、ソウル保持・装備喪失 | P0 |

## カテゴリB: 動的生成

| # | 機能 | 概要 | 優先度 |
|---|---|---|---|
| B-1 | マップ生成 | ダンジョン1階層の動的生成 (MVP後) | P1 |
| B-2 | 敵配置 | 階層難易度に応じた敵スポーン | P1 |
| B-3 | アイテム生成 | 品質パラメータ込みのアイテム生成 | P1 |
| B-4 | UIテンプレートシステム | 動的要素をUIに流し込む基盤 ([GAME_DESIGN.md §6-2](./GAME_DESIGN.md)) | P1 |

## カテゴリC: UI/演出

| # | 機能 | 概要 | 優先度 |
|---|---|---|---|
| C-1 | スキル選択UI | 戦闘中のスキル発動UI | P0 |
| C-2 | HP低下警告演出 | HP依存で画面周囲が赤くなる ([GAME_DESIGN.md §7-2](./GAME_DESIGN.md)) | P1 |
| C-3 | 装備テーマ変動 | 装着装備でライト/ダーク等のテーマ切替 | P2 |
| C-4 | モブ会話・表情変化 | 死亡時ヒント、ナラティブ動的化 | P2 |

## カテゴリD: 配布・デモ

| # | 機能 | 概要 | 優先度 |
|---|---|---|---|
| D-1 | Desktop ビルド | Gradle で Win/Mac/Linux 用 JAR 出力 | P0 |
| D-2 | CI/CD 整備 | GitHub Actions で lint / build / test | P1 |
| D-3 | デモシナリオ | プレイ動画 or ライブデモの構成 | P1 |
| D-4 | Android ビルド | LibGDX Android backend (MVP後) | P2 |

---

## 注記

- 優先度: **P0 = MVP必須** / **P1 = MVP後すぐ** / **P2 = 余力次第**
- カテゴリ番号 (A/B/C/D) は Issue のラベル `category/*` と対応
- 各機能を Issue 化したら、誰でも `Assignees` を自分にして取って良い
- スキル分布や本人の希望を踏まえて取捨選択すること
