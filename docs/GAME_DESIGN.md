## 5. ゲームシステム

### 5-1. システム俯瞰

1. プレイヤーはダンジョンに潜り、敵と戦闘しながら宝箱と金貨を集める
2. 戦闘は **スキル枠 + AP制** のターン制バトル
3. 死亡時: ソウル・スキル・スキル枠を保持、金貨・装備を喪失
4. 生還時: 全持ち帰り、装備耐久は削られた状態で継続
5. 死後の編成画面で **ソウルを消費** してスキル習得・スキル枠拡張・ステータス強化を行う
6. 生還するたびに次のダンジョン難易度が上昇

### 5-2. 戦闘システム (AP制)

#### 基本ルール

- 各エンティティ (プレイヤー・敵) は **行動ポイント(AP)** を持つ
- 各行動には **APコスト** が設定されている (スキル、移動など)
- ターン開始時にAPが回復し、AP切れでターンエンド

#### AP回復方式 (案A-2 採用)

- AP上限は固定
- 毎ターン開始時に **速度ステータス分のAPが回復** する
- AP は **蓄積可能** (上限まで)
- → 「今ターン温存して次ターンに重スキル」という戦略性が生まれる
- → 速度が高い = 1ターンあたりの実質行動回数が多い = 「変動ターン制」の正体

#### 「変動ターン」の表現

- ターンの順序自体は固定 (プレイヤー → 敵 → プレイヤー…)
- ただし速度ステで **1ターン内の行動量** が変動する
- 妖怪ウォッチ3的「攻撃予告 → 自ターンで移動回避」も成立する

#### APコストの設計レンジ (暫定)

| 行動種別 | APコスト |
|---|---|
| 移動1マス | 1 |
| 軽攻撃・軽スキル | 1〜2 |
| 通常スキル | 2〜3 |
| 強スキル | 4〜6 |
| 必殺技 | 7以上 |

数値は実装中に調整する。

#### スキル枠

- プレイヤーは複数の **スキル枠** にスキルを装着して戦闘に持ち込む
- MVP段階のスキル枠数: **4枠**
- スキル枠数はメタ進行で拡張可能 (ソウル消費)
- 移動は基本コマンドとして常時利用可、スキル枠は攻撃・防御・特殊用途

> **MVP 後**: 戦闘はカード式デッキ構築型 (グリッド + AP) に拡張する。詳細は §15-3 / §15-5。

### 5-3. 死亡 / 生還システム

#### 死亡時の挙動

| 要素 | 死亡時 |
|---|---|
| ソウル | **保持** |
| 装着スキル | **保持** |
| スキル枠 (解放数) | **保持** |
| 金貨 | **喪失** |
| 装備 | **喪失** |
| (装備耐久) | 装備自体を失うため対象外 |

#### 生還時の挙動

- ソウル・スキル・スキル枠・金貨・装備 **すべて持ち帰り**
- 装備耐久値は **削られた状態で継続** (リセットされない)
- → タルコフ的ハラハラ感: 生還=大儲け、死亡=大損

> **MVP 後**: 装備耐久は採用しない方針 (§15-9)。装備は常に完全状態で機能、死亡時は喪失のみ。

#### 死後の編成画面

死亡または生還の後、以下の操作を行う:

- ソウルでの **スキル習得** (新規スキルの解放)
- ソウルでの **スキル枠拡張** (装着可能数の増加)
- ソウルでの **ステータス強化** (HP・速度などの永続強化)

これらの解放系操作は **すべて死後** に行う。ダンジョン内では行えない。

### 5-4. ソウル

#### 役割

メタ通貨。本作のメイン進行軸。

#### 獲得手段

- **宝箱** から獲得
- **敵撃破** で獲得
- **武器・スキルの分解** で獲得

#### 使い道

- スキル習得
- スキル枠 解放
- ステータス強化

### 5-5. 難易度進行

- 生還するたびに **次のダンジョンの難易度が上昇**
- 永続強化 (ソウル消費) と難易度上昇のせめぎ合いがリプレイ性の核

### 5-6. ダンジョン構成

#### MVP段階

- 1階層、固定マップ
- 敵1〜2種類
- スキル2〜3個

#### MVP後

- 動的マップ生成
- 階層構造
- Map3つの開放制 (任意)

## 6. 動的生成

### 6-1. 動的生成の対象 (優先順位)

1. マップ (MVP完成後に着手)
2. 敵配置
3. アイテム (品質パラメータを含む)
4. UIレイアウト (テンプレートシステム経由)

### 6-2. UIテンプレートシステム

- UI自体を動的生成するのではなく、**事前定義したテンプレートから選択** する方式
- 動的生成された要素 (スキル、アイテム、敵) を、対応するUIテンプレートに流し込む
- これにより動的生成と UI 表示が疎結合になる

---

## 7. 動的UI/UX

UIに関しては **基盤層 + 演出層** の2レイヤーで設計する。

### 7-1. 基盤層: UIテンプレートシステム

- 上記 6-2 と同じ仕組み
- 全UIをこの基盤上で構築する

### 7-2. 演出層 (基盤層の上に乗る)

| 演出 | 内容 |
|---|---|
| 装備テーマ変動 | 装着装備でライト/ダーク等のテーマが切り替わる、セット装備で専用テーマ |
| 状態フィードバック | HP低下で画面周囲が赤くなる警告演出 (回復で戻る)、その他状態異常演出 |
| ナラティブ動的化 | モブとの会話で選択肢により表情変化、死亡時にヒント表示 |

3つの演出はそれぞれ独立した機能として実装可能。MVP段階では全部を作り込まず、スコープに応じて段階導入する。

> **MVP 後**: 全 UI をポップアップ式サブウィンドウ方式 (FancyMenu Mod 的) に再設計する。詳細は §15-1 / §15-8。

## 9. アーキテクチャ

レイヤー分離型のパッケージ構成を採用する。

```
core/
├── application/    # ゲームループ、画面遷移
├── domain/         # ゲームロジック (フレームワーク非依存)
│   ├── entity/     # プレイヤー、敵
│   ├── battle/     # AP管理、ターン制御、スキル発動
│   ├── skill/      # スキル定義、効果
│   ├── dungeon/    # マップ、階層、宝箱
│   └── meta/       # ソウル、解放、永続データ
├── presentation/   # 描画、UI
│   ├── screen/     # タイトル / ダンジョン / 戦闘 / 編成
│   ├── ui/         # UIテンプレートシステム
│   └── effect/     # 状態演出 (画面警告など)
└── infrastructure/ # I/O、セーブ、アセット読込
```

### 設計原則

- `domain/` は LibGDX に依存しない (将来のWeb移植余地を残す)
- `presentation/` のみが LibGDX API に依存する
- データは `infrastructure/` 経由で読み書きする

## 15. MVP 後の機能仕様

> 本セクションは MVP 完成 (1 階層 / AP 制 / スキル枠装着 / 固定マップ) 以降のゲーム拡張仕様を定める。MVP 自体は §11 を参照。

### 15-1. UI ポリシー: ポップアップ式サブウィンドウ

- 全 UI を **ポップアップ式サブウィンドウ** で構築する (FancyMenu Mod 的なイメージ)
- 「画面遷移」ではなく「**ウィンドウの開閉**」でモードが切り替わる
- ウィンドウは **サイズ・配置を自由に変更可能** (スナップ機能は不要)
- 装備によって **UI テーマが変動** する (§7-2 装備テーマ変動の発展)
- **基本解像度: 1920 × 1080** (フル HD)。現 MVP の 800 × 600 から拡張。ユーザー設定でリサイズ可能とする

### 15-2. 通貨設計: 二層構造

| 通貨 | 性質 | 用途 | 喪失条件 |
|---|---|---|---|
| **ソウル** | 永続 | ソウルツリーで基礎強化・カード習得 (永続) | なし |
| **金貨** | ラン限定 | 層間ノードでカード / 装備 / ステ強化を購入 | 死亡 / ラン終了 |

「死で消える = 金貨 × カード × 装備」「死で残る = ソウル × ステータス基礎」 の二層分離。

### 15-3. カードシステム

#### スキル枠とデッキの併存

- **スキル枠 (装着)**: 常時使える基本動作 (移動・軽攻撃など)。AP コストで発動
- **デッキ (カード)**: AP コスト払って手札からプレイ。応用スキル
- 両者は併存する。スキル枠 = 安定動作、デッキ = 構築要素

#### カード分類

全カードは **タグ (4 種)** × **属性 (物理 / 魔法)** = 8 サブカテゴリに分類:

| タグ | 物理 | 魔法 |
|---|---|---|
| **攻撃** | 斬撃 / 突き / 弓 | 火球 / 雷撃 / 氷柱 |
| **移動** | ダッシュ / 駆け抜け | ショートテレポート / 飛翔 |
| **バフ** | パンプアップ / 戦意高揚 | 精神統一 / 守護 |
| **罠** | 落とし穴 / 撒菱 | 魔法陣 / 凍結床 |

- **ハイブリッドカード** (物理 + 魔法両方) は本編スコープアウト (将来の拡張)

#### AP / 手札 / 山札

- **AP の意味**: §15-4 の「速度ステ」と同義 (1 ターンに使える AP 量)
- **AP 上限はステに含めない**: バフ系で一時超過可能、ただし AP 切れ / 手札切れ / AP 回復タイミングで超過分は保持しない
- **初手ドロー**: 5 枚 (固定、ステ強化対象外)
- **手札上限**: 9 枚
- **ターン終了条件**: AP 切れ **or** 手札切れ → 相手ターンへ
- **構造**: シャドウバースの PP に近い (1 ターン使い切り型)

#### 初期カード

- 移動カード 1 枚を **初期デッキ固定** とする (デッキ事故 = 移動不可で詰むことを防止)

#### 罠カードの寿命

- **物理系**: 踏むまで永続
- **魔法系**: N ターン後に消滅 (代わりにダメージが物理系より強い)
- **重ね掛け禁止**

#### カードの対象範囲

- **攻撃カード**: 上下左右 (4 方向)
- **罠設置**: 自分の周囲 1 マス (8 方向)
- 「攻撃は鋭く、罠は広く」の役割分離

#### カードコスト

- **最低コスト = 1 AP**
- **最大コストは固定上限なし**: ソウルツリーの開放度合いに応じて高コストカードが解放される (序盤は低コストのみ、終盤に大ぶりカードが手に入る)
- カードコスト分布の具体的な調整は実装段階の調整事項

### 15-4. ステータス再定義 (6 種)

| ステ | 役割 |
|---|---|
| **HP** | 生存 |
| **速度** | 1 ターンに使える AP 量 (= AP 回復量と統合) |
| **物理攻撃力** | 物理カード / 罠のダメージ補正 |
| **魔法攻撃力** | 魔法カード / 罠のダメージ補正 |
| **物理防御力** | 物理被ダメ軽減 |
| **魔法防御力** | 魔法被ダメ軽減 |

> 「攻撃力倍率」(現 MVP の `Stats.power` 削除済) を物理 / 魔法に分割。「速度」は AP 回復量と統合した。
> ドロー枚数・AP 最大値はステに含めない (それぞれ固定値・速度で表現)。

### 15-5. 戦闘システム

#### 戦闘形式

- **グリッド (タイルマップ位置あり)** で戦闘する
- 移動カードを切らないと動けない (Slay the Spire 純粋路線)
- 敵接触 (隣接) = 敵ターンで攻撃を受ける

#### シームレスな戦闘進行 (戦闘モードの境界なし)

- **「戦闘モード」という概念は廃止**: ダンジョン探索と戦闘は同一ルール (タイル単位のターン制ローグライク、ToME / Nethack 系)
- **時間進行**: プレイヤーがカードを切るたび 1 ターン経過。プレイヤーが動かない限り敵も動かない (待ち戦術が成立)
- **敵ターンの発動条件**: フィールド上に敵が居れば敵ターンが走る、居なければスキップ
- **手札ウィンドウは常時表示** (ポップアップ常駐、最小化可)
- 戦闘開始 / 終了の明示的な合図はなく、敵の有無で UI 演出が変わるだけ

#### 敵の行動

- **敵も AP を持ち、自分のターンにスキル / カードを使ってくる** (プレイヤーと同じ AP 消費型)
- **敵の AP 量 = 層番号 N** が基本目安 (例: 1 層 → AP 1、5 層 → AP 5、10 層 → AP 10)
  - **強化個体・ボスは +α** (具体値は調整事項)
- 敵がプレイヤーに隣接していれば、敵ターンに攻撃スキルを使用 (= ダメージ)

#### 敵情報の見せ方

- **敵の次行動予告は表示しない** (Slay the Spire 風予告は採用しない)
- 倒した敵は **Bestiary (図鑑) で閲覧可能**: ステータス・特性が記録される
- **未撃破の敵は非表示** (探索感の保持、死んで覚えるデザイン)

### 15-6. 層構造とノード分岐

#### 層構造

- **初期 3 層**、ソウルで層数を拡張可能 (上限解放 + 難易度上昇の複合)
- **N 層目 = N 部屋構成**: 1 層目 = 1 部屋、2 層目 = 2 部屋、… (深いほど複雑)
- **クリア条件 = 最終層のボス撃破** (達成感型エンディング)
- **強化個体**: 5 / 10 階層おきに通常モブの強化版が登場 (中ボス専用キャラは持たない)

#### ノード分岐

- 層内は **Slay the Spire の Act 内マップ式** (層内に複数経路、部屋を選んで進む)
- **層末に 3 択選択**: 5 種類のノードからランダムに 3 つ提示 → 1 つ選択 → 次層へ
- **1 層目だけは戦闘固定** (チュートリアル感、スタート安定)

#### ノード種類

| ノード | 中身 | 出現タイミング |
|---|---|---|
| 通常戦闘 | 雑魚モブ 1〜数体 | 全層 |
| **強化個体戦闘** | エリート (ステ高雑魚) | 5 層おき or 中盤以降 |
| 強化 (ステ / スキル / 装備) | 金貨で購入 | 全層 |
| スキル削除 | 金貨でデッキ圧縮 | 全層 |
| 休憩 | HP 回復 | 全層 |
| イベント | ランダム選択肢 (ハイリスクハイリターン) | 全層 |
| ボス | 最終層のみ | 最終層 |

### 15-7. ソウルツリー (= 永続強化画面)

#### 呼び名・表現

- **呼び名**: **ソウルツリー** (旧称 "編成画面" を置き換え)
- **表現方式**: **円樹形** (中央から外へ広がるスキルツリー)
- ローグライト系の Passive Skill Tree (Path of Exile 風) に近い

#### ツリー構造

- **メイン軸 = ステ強化** (6 ステを伸ばすルート)
- **派生軸 1 = カード取得**: ステ強化 5 個ごとに獲得ノードが出現 (節目報酬)
- **派生軸 2 = 各種拡張**: 層数拡張 / スキル枠拡張 / カード削除枠 / 回復量補正 など (ぽつぽつ散在)
- **その他特殊能力**: 派生報酬として散在配置

イメージ:

```
       [攻+]─[攻+]─[攻+]─[攻+]─[攻+]─◇[強斬撃カード]─[攻+]─...
      /
[中央]─[HP+]─[HP+]─[HP+]─[HP+]─[HP+]─◇[治癒カード]─...
      \                       ▽[層4 開放]
       [速+]─[速+]─[速+]─[速+]─[速+]─◇[神速カード]─...
                  ▽[枠5 開放]
```

- 中央 = 開始地点 / 外側に伸ばす = 強くなる
- ◇ = カード取得 (5 ノードごと) / ▽ = 層数拡張・枠拡張など (ランダム配置)

#### 「職業」の扱い

- **暗黙経路**: 開始は全員同じ (中央)、経路選択で擬似的に職業が決まる
- 物理寄り = 戦士系、魔法寄り = 魔術師系、両方均等 = ハイブリッド
- ゲーム開始時の職業選択は **なし**

### 15-8. ウィンドウ一覧 (ポップアップ式 UI)

ゲーム内で使うウィンドウ (= 開閉単位の UI) の一覧:

| ウィンドウ | 開くタイミング | 概要 |
|---|---|---|
| **タイトル** | 起動時 | 始め / つづき / 設定 |
| **チュートリアルポップ** | 初回起動時 / 設定経由 | 移動・AP・カード使用・敵接触の最低限を説明 |
| **設定** | タイトル / インゲームから | キーコンフィグ・音量等 |
| **チュートリアル** | タイトルから | 操作・カード・ノード・ソウルツリーの解説 |
| **ダンジョン (ワールド)** | プレイ中常時 | タイルマップ表示、移動 |
| **層内マップ (ノード分岐)** | 部屋入退時 | Slay the Spire 風マップ、部屋選択 |
| **手札** | プレイ中常時 (最小化可) | カード手札・AP・敵情報 (戦闘モードの境界なし、常駐) |
| **装備管理** | プレイ中任意 | 装着装備の確認・変更 |
| **インベントリ** | プレイ中任意 | 所持装備・金貨 |
| **層末ノード選択** | 層を抜けたとき | 5→3 提示の選択 UI |
| **ショップ (購入)** | 強化ノード入室時 | 金貨でカード / 装備 / ステ強化を購入 |
| **イベント** | イベントノード入室時 | ランダム選択肢ダイアログ |
| **結果 (死亡 / 生還)** | ラン終了時 | 獲得ソウル・ドロップ表示 |
| **ソウルツリー** | ラン終了後 / つづき選択時 | 円樹形ノード解放 UI |
| **Bestiary** | プレイ中・編成中任意 | 撃破済み敵の図鑑 |
| **セーブ確認** | ラン区切り | セーブ → 終了 / 続行 |

#### メインループ (画面遷移)

```
[起動] → タイトル
  ├─ 始め → (初回のみ) チュートリアルポップ → ラン開始 (層1 → ノード → ... → 最終層ボス)
  │                                              ↓ (撃破 or 死亡)
  │                                           結果ウィンドウ → ソウルツリー → セーブ → タイトル / 続行
  ├─ つづき → ソウルツリー (前ランから引き継ぎ) → ラン開始
  └─ 設定 (チュートリアル再表示も可能)
```

### 15-9. 装備

- **ステ補正**: HP / 速度 / 物攻 / 魔攻 / 物防 / 魔防 のいずれかに加算
- **テーマ変動**: 装着装備の系統で UI テーマが変動 (§15-1 / §7-2 と連動)
- **装備固有カード**: 装備を着けると **対応するカードが自動でデッキに入る** (外すとデッキから抜ける)
- **耐久値はない** (常に完全状態で機能)
- **特殊能力はない** (シンプル化方針)
- 死亡時は装備自体を喪失 (§5-3 維持)

### 15-10. チュートリアル

- 初回起動時、最初の戦闘 (1 層目 = 戦闘固定、§15-6) に入る前に **軽い説明ポップアップ** を表示
- 内容: 移動カード / AP / カード使用 / 敵接触ルール の最低限
- タイトル画面に独立した「チュートリアル」項目は **置かない**
- 設定画面から **再表示可能** にする (見直したい時のため)

### 15-11. セーブシステム

- セーブ対象 = **層単位の状態 + 永続強化情報**
  - 永続: ソウル残量、ソウルツリー進捗、Bestiary
  - ラン中: 現在の層番号、層開始時のデッキ・装備・金貨・HP (= 直前の層末状態)
- セーブタイミング: **層と層の間** (層を抜けたとき / 次の層に入る前)
- 復帰時: セーブされた **層の最初の状態** から再開 (戦闘途中・部屋途中はセーブされない)
- セーブスロット: 1 つ (単純ラン継続)
