## 3. 技術スタック

### 3-1. 言語・ランタイム

- **Java 25 LTS** (Oracle JDK 25)

### 3-2. フレームワーク

- **LibGDX**

- **コーディング規約**: Google Java Style Guide

## 5. ゲームシステム

### 5-1. システム俯瞰

1. プレイヤーはダンジョンに潜り、敵と戦闘しながら宝箱と金貨を集める
2. 戦闘は **スキル枠 + AP制** のターン制バトル
3. 死亡時: ソウル・スキル・スキル枠を保持、金貨・装備を喪失
4. 生還時: 全持ち帰り、装備耐久は削られた状態で継続
5. 死後の編成画面で **ソウルを消費** してスキル習得・スキル枠拡張・ステータス強化を行う
6. 生還するたびに次のダンジョン難易度が上昇

### 5-2. 戦闘システム (AP制)

#### 基本ルール

- 各エンティティ (プレイヤー・敵) は **行動ポイント(AP)** を持つ
- 各行動には **APコスト** が設定されている (スキル、移動など)
- ターン開始時にAPが回復し、AP切れでターンエンド

#### AP回復方式 (案A-2 採用)

- AP上限は固定
- 毎ターン開始時に **速度ステータス分のAPが回復** する
- AP は **蓄積可能** (上限まで)
- → 「今ターン温存して次ターンに重スキル」という戦略性が生まれる
- → 速度が高い = 1ターンあたりの実質行動回数が多い = 「変動ターン制」の正体

#### 「変動ターン」の表現

- ターンの順序自体は固定 (プレイヤー → 敵 → プレイヤー…)
- ただし速度ステで **1ターン内の行動量** が変動する
- 妖怪ウォッチ3的「攻撃予告 → 自ターンで移動回避」も成立する

#### APコストの設計レンジ (暫定)

| 行動種別 | APコスト |
|---|---|
| 移動1マス | 1 |
| 軽攻撃・軽スキル | 1〜2 |
| 通常スキル | 2〜3 |
| 強スキル | 4〜6 |
| 必殺技 | 7以上 |

数値は実装中に調整する。

#### スキル枠

- プレイヤーは複数の **スキル枠** にスキルを装着して戦闘に持ち込む
- MVP段階のスキル枠数: **4枠**
- スキル枠数はメタ進行で拡張可能 (ソウル消費)
- 移動は基本コマンドとして常時利用可、スキル枠は攻撃・防御・特殊用途

### 5-3. 死亡 / 生還システム

#### 死亡時の挙動

| 要素 | 死亡時 |
|---|---|
| ソウル | **保持** |
| 装着スキル | **保持** |
| スキル枠 (解放数) | **保持** |
| 金貨 | **喪失** |
| 装備 | **喪失** |
| (装備耐久) | 装備自体を失うため対象外 |

#### 生還時の挙動

- ソウル・スキル・スキル枠・金貨・装備 **すべて持ち帰り**
- 装備耐久値は **削られた状態で継続** (リセットされない)
- → タルコフ的ハラハラ感: 生還=大儲け、死亡=大損

#### 死後の編成画面

死亡または生還の後、以下の操作を行う:

- ソウルでの **スキル習得** (新規スキルの解放)
- ソウルでの **スキル枠拡張** (装着可能数の増加)
- ソウルでの **ステータス強化** (HP・速度などの永続強化)

これらの解放系操作は **すべて死後** に行う。ダンジョン内では行えない。

### 5-4. ソウル

#### 役割

メタ通貨。本作のメイン進行軸。

#### 獲得手段

- **宝箱** から獲得
- **敵撃破** で獲得
- **武器・スキルの分解** で獲得

#### 使い道

- スキル習得
- スキル枠 解放
- ステータス強化

### 5-5. 難易度進行

- 生還するたびに **次のダンジョンの難易度が上昇**
- 永続強化 (ソウル消費) と難易度上昇のせめぎ合いがリプレイ性の核

### 5-6. ダンジョン構成

#### MVP段階

- 1階層、固定マップ
- 敵1〜2種類
- スキル2〜3個

#### MVP後

- 動的マップ生成
- 階層構造
- Map3つの開放制 (任意)

## 6. 動的生成

### 6-1. 動的生成の対象 (優先順位)

1. マップ (MVP完成後に着手)
2. 敵配置
3. アイテム (品質パラメータを含む)
4. UIレイアウト (テンプレートシステム経由)

### 6-2. UIテンプレートシステム

- UI自体を動的生成するのではなく、**事前定義したテンプレートから選択** する方式
- 動的生成された要素 (スキル、アイテム、敵) を、対応するUIテンプレートに流し込む
- これにより動的生成と UI 表示が疎結合になる

---

## 7. 動的UI/UX

UIに関しては **基盤層 + 演出層** の2レイヤーで設計する。

### 7-1. 基盤層: UIテンプレートシステム

- 上記 6-2 と同じ仕組み
- 全UIをこの基盤上で構築する

### 7-2. 演出層 (基盤層の上に乗る)

| 演出 | 内容 |
|---|---|
| 装備テーマ変動 | 装着装備でライト/ダーク等のテーマが切り替わる、セット装備で専用テーマ |
| 状態フィードバック | HP低下で画面周囲が赤くなる警告演出 (回復で戻る)、その他状態異常演出 |
| ナラティブ動的化 | モブとの会話で選択肢により表情変化、死亡時にヒント表示 |

3つの演出はそれぞれ独立した機能として実装可能。MVP段階では全部を作り込まず、スコープに応じて段階導入する。

## 8. AI使用方針

### 8-1. 用途別方針

| 用途 | 方針 |
|---|---|
| コード生成 | 積極使用 |
| アセット生成 (画像) | GPT で同一パターンを複数枚生成して採用 |
| アセット生成 (サウンド) | 必要なら VOICEVOX 等を利用 |
| 設計 | AI主導 |
| レビュー | AI使用可だが **人間レビューを必ず通す** |

### 8-2. AI支援用 Skills

- リポジトリ内の `.claude/skills/` に AI 支援用のスキル定義を配置する
- 整備フェーズで作成
- 全メンバーが同じ AI 出力傾向で開発できるようにする

## 9. アーキテクチャ

レイヤー分離型のパッケージ構成を採用する。

```
core/
├── application/    # ゲームループ、画面遷移
├── domain/         # ゲームロジック (フレームワーク非依存)
│   ├── entity/     # プレイヤー、敵
│   ├── battle/     # AP管理、ターン制御、スキル発動
│   ├── skill/      # スキル定義、効果
│   ├── dungeon/    # マップ、階層、宝箱
│   └── meta/       # ソウル、解放、永続データ
├── presentation/   # 描画、UI
│   ├── screen/     # タイトル / ダンジョン / 戦闘 / 編成
│   ├── ui/         # UIテンプレートシステム
│   └── effect/     # 状態演出 (画面警告など)
└── infrastructure/ # I/O、セーブ、アセット読込
```

### 設計原則

- `domain/` は LibGDX に依存しない (将来のWeb移植余地を残す)
- `presentation/` のみが LibGDX API に依存する
- データは `infrastructure/` 経由で読み書きする

## 10. データモデル (概観)

実装着手時に詳細化する。

- **スキルマスタ** (JSON/YAML): ID、名前、APコスト、効果、解放コスト
- **敵マスタ**: ID、HP、AP、速度、行動パターン
- **装備マスタ**: ID、名前、ステ補正、耐久値
- **セーブデータ**: ソウル残量、解放済みスキル、装着スキル、装備、装備耐久、難易度進行度

## 11. MVP定義

### 11-1. MVP

> **2Dダンジョンを1階層、AP制の変動ターン制で探索しスキル選択で戦闘、死んだらソウルが残る最小ループ (Desktop版のみ)**

### 11-2. MVPに含む

- 2Dタイルマップの描画 (固定1階層)
- プレイヤー移動 (AP制)
- 敵1〜2種類、行動AI最小限
- スキル2〜3個、スキル枠4個
- 戦闘 (AP管理、ターン制御)
- 死亡判定
- ソウルの **獲得と保持** (使用UIはMVP後)

### 11-3. MVPに含まない (スコープアウト)

- 動的マップ生成
- Map3つ開放制
- Android対応
- 動的UI/UX演出 (テーマ変動、警告演出など)
- サウンド
- 装備システム
- ソウルの使用 (スキル習得/枠拡張/ステ強化のUI)
- マルチエンディング
- セーブ機能の作り込み

## 13. 用語集

| 用語 | 定義 |
|---|---|
| AP | 行動ポイント。各エンティティが持ち、行動するたびに消費する。 |
| スキル枠 | プレイヤーが戦闘に持ち込めるスキルの装着スロット。 |
| ソウル | メタ通貨。死後の編成画面で永続強化に使用する。 |
| ローグライト | ローグライクにメタ進行 (永続強化) を加えたジャンル。 |
| 変動ターン制 | ターン順は固定だが、速度ステで1ターン内の行動量が変わる方式。 |
